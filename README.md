# 💉 Vaccine Management System

A simple and efficient **Vaccine Management System** built as a dummy learning project by our team.  
It allows users to **register**, **login**, **book vaccine appointments**, and for admins to manage vaccine availability.

---
✨ Features
👤 User Registration & Login with validation

📅 Appointment Booking & Management

🧑‍⚕️ Admin Dashboard for managing vaccines and users

📬 Instant appointment confirmation through dashboard updates

🔐 Secure form handling and basic authentication

---

🧰 Tech Stack

Category	Technologies Used
Frontend	HTML, CSS, Tailwind CSS, JavaScript
Backend	PHP
Database	MySQL
Server	XAMPP (Apache + MySQL)

## 🧪 How to Run Locally

- Install XAMPP

- Place the project folder in: C:\xampp\htdocs\

- Start Apache and MySQL from the XAMPP control panel

- Open phpMyAdmin and import the vaccination.sql file

- Navigate to http://localhost/VACC in your browser

---

## 🗃️ Database Setup
Create a new database (e.g., vaccination_db) in phpMyAdmin

Import the provided .sql file

Update your database credentials in connection.php or db_config.php
